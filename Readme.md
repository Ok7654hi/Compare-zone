# 📱 Compare Zone

**Choose Best. Stay Ahead.**

Compare Zone is a modern smartphone comparison website that helps users compare phones, view detailed specifications, track prices, and discover the latest smartphone launches.

## Features

- 📱 Phone Comparison
- 🔍 Smart Search
- 🏷️ Brand Pages
- 🤖 AI Recommendations
- 💰 Price Tracking
- ❤️ Wishlist
- ⭐ Reviews & Ratings
- 👤 User Accounts
- 🛠️ Admin Dashboard
- 🌙 Dark Mode
- 📱 Responsive Design

## Technology

- HTML5
- CSS3
- JavaScript
- Node.js
- Express.js
- MongoDB
